FitBox v0.1.0 is an offline Android testing build based on the supplied Figma design.

Includes local onboarding, front/back muscle references, manual rep tracking, pause/resume timers, saved partial sessions, daily goals, XP, streaks, exercise guides, insights, rest days, and JSON export.

Android 8.0+ required. Package: com.fitbox.app. Debug signed for testing.

No ML/DL model, camera form detection, Bluetooth hardware connection, online authentication, or cloud sync is included. The web preview and APK keep separate device-local data.

See the repository README for screenshots, build instructions, architecture, validation, and roadmap.
