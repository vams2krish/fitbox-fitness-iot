# FitBox v0.2 implementation and validation

This record supersedes v0.1 implementation statements in DESIGN.md, ROADMAP.md and VALIDATION.md. Updated November 17, 2026.

## Implemented

Bundled on-device MediaPipe inference, 15 experimental pose tasks, 7 manual tasks, local guided trainer selection/onboarding, account-based text-summary sync on Neon, sequential daily tasks, body preference and anatomy check-up views, private local video review/recording, and Android secure-origin camera support. The model is pretrained: this repository performs inference and deterministic exercise rules, not model training.

## Next work and blockers

Stripe sandbox is provisioned with three recurring USD prices. Signed events and fresh provider retrieval determine membership; redirects do not grant access. Live API keys/events are refused. The test suite uses Stripe test tokens, never real payment cards. FitBox has no sending domain; the user requested dummy email for now, so previews never deliver mail. Verification/recovery remain unavailable. No unrelated product domain or key is connected.

Continue Figma state audit when detailed access is restored. Validate exercise rules, camera positions, occlusion and movement ranges using consented, licensed recordings and physical devices. BLE needs real advertised identifiers, services/characteristics, authentication, message units, sequence/timestamps and reconnect behavior. Release signing, instructor/content review, privacy policy and store packaging remain production work. This APK is debug signed.
