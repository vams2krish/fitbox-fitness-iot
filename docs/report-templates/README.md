# FitBox workout email templates

Fictional sample data only. No email has been sent. The app generates personalized reports from the signed-in user’s own logs; these files demonstrate the reusable design and content.

| Period | HTML preview | Plain text | Worklog |
| --- | --- | --- | --- |
| daily | [HTML](daily.html) | [Text](daily.txt) | [CSV](daily-worklog.csv) |
| weekly | [HTML](weekly.html) | [Text](weekly.txt) | [CSV](weekly-worklog.csv) |
| monthly | [HTML](monthly.html) | [Text](monthly.txt) | [CSV](monthly-worklog.csv) |
| yearly | [HTML](yearly.html) | [Text](yearly.txt) | [CSV](yearly-worklog.csv) |

Daily reviews emphasize the current day; weekly reviews show active days and movement mix; monthly reviews show weekly patterns; yearly reviews include monthly training patterns. All include comparison with the previous corresponding calendar period, real logged work, technical tracking metrics when available, bounded improvement suggestions and clear non-delivery labels. Current partial periods are not normalized or extrapolated.
