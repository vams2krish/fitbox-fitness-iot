# FitBox v0.3.0 — connected wellness journey

This Android/web testing release restores the requested product flows around the on-device camera and authenticated backend.

- Trainer-first FTUE: John/Tina, six activity categories with multiple selection, required report-email capture, guided preference conversation, illustrated Body Center and desired-body Goal Center, and a replayable four-step tutorial.
- Mystery Task Center: every unfinished task begins concealed. Only the currently eligible card can be revealed; complete and claim it to unlock the next. Revealing never spends points or charges money.
- Congratulations with recorded session/day stats, Task done labels, Sweat Points, Goal Points, earned level-up screens and personal Goal Center targets.
- Draggable in-app coach bubble, unread local notifications, Message/Doubt Centers, daily check-ins and day-end analysis prompts.
- Learning Center search, categories, saved favorites, practiced labels, exercise instructions and camera setup.
- Genuine WebGL 3D reference mannequin with drag/keyboard rotation, front/back controls and wheel/pinch zoom; recorded activity stats. This is a stylized reference, not a personalized body scan or clinical anatomy model.
- Go premium and Subscribe me pricing popup; three real Stripe sandbox plans. Confirmed membership shows a crown and gold avatar rim; the browser return URL alone grants no membership.
- Day-end analysis, persistent 1–5 experience ratings with labels, and a daily report email preview addressed to the email supplied in account details.

Email delivery remains demo-only, as requested. Nothing is sent or scheduled externally. Prior-day reports are prepared when the app is opened; no outside-app coach overlay or OS background notification service is claimed. Local goals, reveals, favorites, notifications and reviews persist on the device; workout records and selected profile fields sync only with consent. Camera frames, landmarks and videos stay on-device.

SP = one point per saved rep plus one per five tracked hold seconds (manual timed practice uses active seconds). GP = 25 per claimed daily task. Every 100 GP advances one level. These are app progress currencies with no cash value or paid randomized rewards.

Android 8.0+ with a recent Android System WebView. Debug signed, intended for testing. Physical-phone exercise accuracy and complete pixel/state parity with every Figma variant remain unverified; this release does not claim that all source artwork or a true personalized 3D model has been recovered.
