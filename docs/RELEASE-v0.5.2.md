# FitBox v0.5.2 — clearer 3D interaction

- The Home athlete viewport now has a visible rotation icon and a high-contrast “Drag to rotate” hint. The canvas uses grab/grabbing cursors on desktop.
- Replaced the tiny expand glyph with a labelled violet Expand button and a 44 px minimum touch target.
- The larger athlete view includes a matching Shrink view button returning to Home.
- Corrected the panel sizing so the controls, athlete and four training stats remain visible together.

Verified real drag rotation, expand/shrink navigation, and unclipped layouts at 320, 375, 390 and 961 px. Android version 0.5.2/build 8 retains the previous debug signing certificate. Android 8+ testing build; other workout, tracking, billing and email behavior is unchanged.
